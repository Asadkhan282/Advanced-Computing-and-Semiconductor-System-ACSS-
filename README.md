# ACSS — Advanced Computing and Semiconductor System

**Engineering the Future of Computing.**

ACSS is an engineering and research initiative focused on advanced computing, semiconductor systems, and efficient AI infrastructure.

## Current featured research

### MemCore

MemCore is an experimental memory-management and scheduling simulator for AI inference workloads.

It investigates memory placement, eviction policies, reuse prediction, deadline-aware scheduling, and adaptive memory management across synthetic workloads.
